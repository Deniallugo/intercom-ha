# Archive — design history, not current documentation

These specs were written before or during the work they describe and have not
been kept up to date since. Open checkboxes, file names and numbers here may not
match the code: files were renamed or removed, and designs changed once real
hardware was measured. They are kept as a record of why things were built the
way they were.

For how things work now, read the top-level `README.md`, `docs/DEVICES.md`,
the device configs in `devices/` and the READMEs under `hardware/`.
